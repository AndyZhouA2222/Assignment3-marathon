# Marathon UI · React

`marathon.css` + `Marathon.tsx` are the component library documented in `.claude/skills/marathon-ui-style/SKILL.md` (section 11, kept in sync). `Demo.tsx` assembles a sample page; screenshots are in `screenshots/`.

Fonts: the CSS prefers locally installed originals (KH Interference, Shapiro Wide, IvyPresto Headline, Fraktion Mono) via `local()` and falls back to Chakra Petch / Archivo / Instrument Serif / JetBrains Mono.
