# Marathon UI · React

`marathon.css` + `Marathon.tsx` are the component library documented in `../../SKILL.md` (section 11). `Demo.tsx` assembles a sample page; screenshots are in `../../references/screenshots/`.

Fonts: the CSS prefers locally installed originals (KH Interference, Shapiro Wide, IvyPresto Headline, Fraktion Mono) via `local()` and falls back to Chakra Petch / Archivo / Instrument Serif / JetBrains Mono.

Preview from the repo root: `npm run demos && npm run shots` → `out/shots/marathon-ui-*.png`.
